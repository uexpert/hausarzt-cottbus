# docs-new-feature.md
Document newly implemented features or modules in the Fullstack project.

1. Detect new frontend components/services and backend endpoints/classes.
2. Update:
   - PROJECT_OVERVIEW.md
   - Angular_Structure.md

   - Business_Rules.md

3. Add summary entry to CHANGELOG.md.

Usage:
